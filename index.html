Hermes Personal Dashboard

Hermes Personal Dashboard is a self-hosted assistant integration for its owner's personal accounts. It helps the owner find and summarize email, calendar entries, contacts, documents and files using the Google permissions granted to each connection.

The ordinary connections use read permissions. Any separately enabled writing capability follows its own permission and approval controls. Publishing this information page does not grant anyone access to an account or to the owner's Hermes server.

This is a personal-use integration, not a public hosted service. There is no public registration or account-sharing service.

Read the privacy information. Contact the operator using the support email shown on the Google authorization screen.
